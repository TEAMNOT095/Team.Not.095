Quick guides

Create a restore point
  1. Press the Windows key, type "Create a restore point" and open it.
  2. On the System Protection tab, select the C: drive. If protection is off, click Configure, turn it on, then click Apply.
  3. Click Create, give it a name, and click Create again.
Back up the registry before a .reg tweak
  1. Press Win + R, type regedit and press Enter.
  2. Click File, then Export.
  3. Set Export range to All, name the file and save it.
  4. To restore, double-click the saved .reg file.
Run a script as administrator
  1. BAT or CMD: right-click the file and choose Run as administrator.
  2. PowerShell: open PowerShell as administrator, then allow scripts for this session only: Set-ExecutionPolicy -Scope Process -ExecutionPolicy Bypass
  3. Run the script, for example: .\\script.ps1
Check a download before running it
  1. Upload the file to virustotal.com and read the report.
  2. To get its SHA-256 hash in PowerShell: Get-FileHash .\\file.ext -Algorithm SHA256
Find what slows your startup
  1. Press Ctrl + Shift + Esc to open Task Manager.
  2. Open the Startup tab (Startup apps on Windows 11) and sort by Startup impact.
  3. Right-click anything you do not need and choose Disable.

FAQ

Is it safe to run these scripts?

They change system settings, so treat them with care. Create a restore point, read each script, start with the basic cleaning and latency tweaks, and keep anything marked Advanced for when you understand what it does.

Can I undo the changes?

A restore point lets you roll back most changes. Back up first, because registry tweaks and some scripts do not always have an automatic undo.

Which Windows versions are supported?

The toolkit targets Windows 10 and 11. Some files are version-specific, so check the file name and notes before running.

Why are some items marked Advanced?

They disable protections such as Defender, Spectre/Meltdown mitigations, DEP or Windows Update. That can improve speed on some systems, but it reduces security.

Where can I get the files?

Use the Get the full collection button in the library, or open the Discord channels and Mega folders in the Resources section.
